# Security policy

Please do not open a public issue, discussion or pull request for a suspected vulnerability.

## Reporting a vulnerability

Email **security@openpush.ai**, or use GitHub's private vulnerability reporting on this repository
(Security → Report a vulnerability). Include the affected version, a minimal reproduction, the
impact you observed, and any suggested remediation.

Never include real device credentials, provider tokens, SDK keys, or personal data in a report;
use placeholders instead.

We aim to acknowledge reports within 3 business days, and we will keep you informed while we
investigate and fix the issue.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.2.x   | Yes       |
| < 1.2   | No        |

Security fixes are released as patch versions of the supported line.
